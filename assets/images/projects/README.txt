PROJECT GALLERY UPLOADS
=======================

Upload completed-event photos into this folder:
assets/images/projects/

Supported file formats:
- .webp (recommended for fastest loading)
- .jpg / .jpeg
- .png

The Gallery page reads this folder automatically, so new images will appear without editing gallery.php.
Use simple descriptive filenames, for example:
- walima-buffet-islamabad.webp
- corporate-launch-catering.webp
- birthday-dessert-table.webp

For performance, resize large photos to around 1600px wide and compress them before uploading.
